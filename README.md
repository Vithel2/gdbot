# Komnataria

## Скачать уровень

- `levels/komnataria-original.gdlvl` — исходный файл пользователя, без изменений.
- `levels/komnataria-deco.gdlvl` — копия с новым оформлением, имя при импорте: `komnataria deco`.

В новой копии добавлено 966 декоративных объектов: фоновые архитектурные панели трёх типов, рамы, потолочные световые акценты и названия участков. Палитра сочетает тёмный фиолетовый, малиновый и приглушённый голубой. Новые объекты используют независимые цветовые каналы 801–808, задний план B4 и слой редактора 20. Все исходные записи объектов, включая препятствия, порталы и триггеры, сохранены побайтно и в прежнем порядке. Из исходных настроек оформления изменён начальный цвет фона.

Файл проверен распаковкой и сравнением исходных записей. Импорт и вид в Geometry Dash пока не проверены: стоит открыть копию в редакторе и проверить масштаб фоновых панелей, порядок отрисовки и читаемость сложных участков. Рейт уровня зависит от качества результата в игре и решения модераторов/RobTop; он не гарантирован.

Скрипт `python tools/build_decor.py` воспроизводит оформление из оригинала без дополнительных библиотек. Старый проект бота остаётся в истории Git.
