# Komnataria — Night Bloom

[Скачать новую копию уровня](https://github.com/Vithel2/gdbot/raw/refs/heads/main/levels/komnataria-deco.gdlvl)

При импорте копия называется **komnataria bloom**. Оригинал последнего присланного файла сохранён отдельно: `levels/komnataria-original.gdlvl`.

## Что изменено

- Внутреннее оформление блоков: цветные грани, нижние тени, боковая подсветка и небольшие вставки.
- Цветные внутренние детали шипов и наклонных конструкций, сохраняющие исходный внешний контур.
- Световые полосы вдоль открытых верхних граней блоков.
- Редкие фоновые силуэты вместо панелей из предыдущей версии.
- Шесть палитр с переходами: фиолетовая, синяя, бирюзовая, розовая, сиреневая и тёплая финальная.
- Пять мягких пульсаций акцентного цвета после переходов и две надписи.

Это авторская процедурная переработка. Acu 2 использован как референс принципов слоёв и цветовых каналов; его секции и группы не перенесены. Синхронизация с музыкой не проверена; переходы привязаны к позициям уровня.

## Проверка

Файл повторно распакован и разобран. Все исходные записи объектов, включая препятствия, порталы и триггеры, сохранены без изменений и в том же порядке. Добавленные видимые объекты имеют `No Touch` (ключ 121), чтобы не создавать хитбоксы. Новые триггеры управляют только цветом. Уровень не удлинён новыми объектами. Числа записей из файла доступны в `levels/decor-report.json`; счётчик редактора может отличаться.

Импорт, порядок отрисовки, читаемость и производительность в Geometry Dash 2.209b пока **не проверены в игре**. Перед публикацией откройте копию в редакторе и проверьте прохождение. Получение рейта не гарантировано.

## Воспроизведение

`python tools/build_decor.py` собирает копию из оригинала, используя только стандартную библиотеку Python. Добавленные детали находятся на слое редактора 20, цветовые каналы — 801–809. Для деталей движущихся объектов наследуются исходные группы. Исходные цвета объектов сохранены; изменены начальные цвета фона и земли.

Справочник формата: [GDDocs — Object String](https://wyliemaster.github.io/gddocs/#/resources/client/level-components/level-string).
