# GD Trainer

Небольшой экспериментальный тренажёр для Geometry Dash на Windows. Он подбирает последовательность нажатий пробела методом случайных мутаций: сохраняет лучшую попытку и меняет её в следующих попытках. Программа экспериментально считывает зелёную полосу прогресса и останавливает попытку, если обнаружит её резкое уменьшение после перезапуска. Полученный процент нужно проверить и подтвердить вручную. Она не распознаёт препятствия и не гарантирует прохождение: уровень должен запускаться одинаково, а длинные и сложные уровни могут потребовать много попыток. Работу именно с версией 2.209b нужно проверить на компьютере с игрой.

## Запуск

1. Установите Python 3 для Windows с компонентом Tcl/Tk. Для захвата экрана нужен Pillow; start.bat установит его при первом запуске через pip и интернет.
2. Распакуйте архив целиком и запустите `start.bat` двойным щелчком. Он использует Python 3.12. Если программа завершится с ошибкой, окно с текстом ошибки останется открытым — сделайте его снимок. Если Python 3.12 не установлен, в терминале можно запустить `py -3 app.py`.
3. Запустите Geometry Dash в оконном или безрамочном режиме, откройте нужный уровень. В тренажёре нажмите «Обновить» и выберите окно игры по названию.
4. Укажите уникальное название уровня и длительность попытки. Запустите попытку в самом начале уровня: тренажёр переключится в выбранное окно и начнёт нажимать пробел. После завершения проверьте предложенный процент и исправьте его при необходимости. Если игра перезапускает уровень автоматически, ориентируйтесь на результат первой попытки.
5. Вручную вернитесь к началу уровня и повторите. Лучший результат и последовательность сохраняются отдельно по названию уровня в `%LOCALAPPDATA%\GDTrainer\profiles.json`. Для изменения длительности используйте новое название профиля.

Ввод остановится при потере фокуса игры либо по кнопке «Стоп». Кнопка отменяет попытку без сохранения результата. Из-за переключения фокуса интервалы могут немного меняться; программа не отслеживает смерть и может продолжить нажатия до конца заданного времени. Для тестирования используйте обычные уровни без соревновательных функций.

Полоса должна быть видна сверху в стандартном расположении. Считывание может не сработать на нестандартном интерфейсе, при перекрытом окне, изменённом масштабе или смерти в самом начале. При отсутствии надёжной оценки введите процент вручную. Сброс определяется после появления прогресса в новой попытке, поэтому несколько нажатий после смерти возможны. Не используйте оценку, если она неверна. Захват экрана пока проверен только на искусственном изображении, а не с работающей игрой.
