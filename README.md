# GD Trainer

Небольшой экспериментальный тренажёр для Geometry Dash на Windows. Режим анализа пробует реагировать на яркие контуры прямо перед кубом; он рассчитан на стандартную камеру и не распознаёт тип объектов. Возможно множество ошибок, особенно на других уровнях, с украшениями и другими режимами персонажа. Он не обучается автоматически. Отключите галочку анализа, чтобы использовать старый подбор последовательностей. Он подбирает последовательность нажатий пробела методом случайных мутаций: сохраняет лучшую попытку и меняет её в следующих попытках. Программа экспериментально считывает зелёную полосу прогресса и останавливает попытку, если обнаружит её резкое уменьшение после перезапуска. Полученный процент нужно проверить и подтвердить вручную. Она не распознаёт препятствия и не гарантирует прохождение: уровень должен запускаться одинаково, а длинные и сложные уровни могут потребовать много попыток. Работу именно с версией 2.209b нужно проверить на компьютере с игрой.

## Запуск

1. Установите Python 3 для Windows с компонентом Tcl/Tk. Для захвата экрана нужен Pillow; start.bat установит его при первом запуске через pip и интернет.
2. Распакуйте архив целиком и запустите `start.bat` двойным щелчком. Он использует Python 3.12. Если программа завершится с ошибкой, окно с текстом ошибки останется открытым — сделайте его снимок. Если Python 3.12 не установлен, в терминале можно запустить `py -3 app.py`.
3. Запустите Geometry Dash в оконном или безрамочном режиме, откройте нужный уровень и поставьте его на паузу. В тренажёре нажмите «Обновить» и выберите окно игры по названию.
4. Укажите уникальное название уровня и длительность попытки. Оставьте галочку запуска с паузы включённой и запустите попытку: тренажёр переключится в выбранное окно и нажмёт пробел. Запуск с паузы не проверен на реальной игре. После завершения проверьте предложенный процент и исправьте его при необходимости. Если игра перезапускает уровень автоматически, ориентируйтесь на результат первой попытки.
5. Вручную вернитесь к началу уровня и повторите. Лучший результат и последовательность сохраняются отдельно по названию уровня в `%LOCALAPPDATA%\GDTrainer\profiles.json`. Длительность можно менять от 1 до 300 секунд; по умолчанию 120.

Ввод остановится при потере фокуса игры либо по кнопке «Стоп». Кнопка отменяет попытку без сохранения результата. Из-за переключения фокуса интервалы могут немного меняться; программа не отслеживает смерть и может продолжить нажатия до конца заданного времени. Для тестирования используйте обычные уровни без соревновательных функций.

Полоса должна быть видна сверху в стандартном расположении. Считывание может не сработать на нестандартном интерфейсе, при перекрытом окне, изменённом масштабе или смерти в самом начале. При отсутствии надёжной оценки введите процент вручную. Сброс определяется после появления прогресса в новой попытке, поэтому несколько нажатий после смерти возможны. Не используйте оценку, если она неверна. Захват экрана пока проверен только на искусственном изображении, а не с работающей игрой.

## Просмотр и запись

Запустите `viewer.bat`, выберите окно игры и нажмите «Просмотр». При первом запуске устанавливаются Pillow и OpenCV. Разместите окно игры так, чтобы оно было видно и не перекрывалось: захват считывает экран. Вторая программа показывает снимки игры и использует те же функции анализа, что бот, но работает отдельно и может немного отставать; это не точная запись внутренних состояний бота. Жёлтая рамка показывает область поиска ярких контуров, красная — срабатывание; голубая — область полосы прогресса. Нажмите «Запись MP4», выберите файл, а после попытки нажмите «Остановить запись» для сохранения. Видео записывается без звука с целевой частотой 10 кадров в секунду; если захват медленный, длительность видео может отличаться от реального времени.

Автоматическое определение смерти пока ненадёжно: программа пытается заметить уменьшение полосы после перезапуска, а не распознаёт смерть. Она не запускает серию попыток с ожиданием в одну секунду. Не считайте эту версию полноценным обучающимся ботом.
