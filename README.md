# GD Trainer

Небольшой экспериментальный тренажёр для Geometry Dash на Windows. Он подбирает последовательность нажатий пробела методом случайных мутаций: сохраняет лучшую попытку и меняет её в следующих попытках. Прогресс вводится вручную по показаниям игры. Это не распознавание картинки и не гарантия прохождения: уровень должен запускаться одинаково, а длинные и сложные уровни могут потребовать много попыток. Работу именно с версией 2.209b нужно проверить на компьютере с игрой.

## Запуск

1. Установите Python 3 для Windows с компонентом Tcl/Tk. Дополнительные библиотеки не нужны.
2. Запустите `python app.py`.
3. Запустите Geometry Dash в оконном или безрамочном режиме, откройте нужный уровень. В тренажёре нажмите «Обновить» и выберите окно игры по названию.
4. Укажите уникальное название уровня и длительность попытки. Запустите попытку в самом начале уровня: тренажёр переключится в выбранное окно и начнёт нажимать пробел. После завершения введите достигнутый процент. Если игра перезапускает уровень автоматически, ориентируйтесь на результат первой попытки.
5. Вручную вернитесь к началу уровня и повторите. Лучший результат и последовательность сохраняются отдельно по названию уровня в `%LOCALAPPDATA%\GDTrainer\profiles.json`. Для изменения длительности используйте новое название профиля.

Ввод остановится при потере фокуса игры либо по кнопке «Стоп». Кнопка отменяет попытку без сохранения результата. Из-за переключения фокуса интервалы могут немного меняться; программа не отслеживает смерть и может продолжить нажатия до конца заданного времени. Для тестирования используйте обычные уровни без соревновательных функций.
