# Komnataria

Исходный экспорт уровня Geometry Dash находится в `levels/komnataria-original.gdlvl`. Он сохранён без изменений. Предыдущий проект бота удалён из текущей версии репозитория и остаётся в истории Git.

`levels/komnataria-deco.gdlvl` — экспериментальная копия: начальный цвет фона изменён с ярко-малинового на более тёмный бордовый для контраста. Все записи объектов и их порядок сохранены. Цветовые триггеры в уровне могут менять фон во время прохождения. Импорт и внешний вид в игре не проверены; исходный файл остаётся отдельно.
